# CargoFlow: Design notes

The page's colours and fonts live in `index.html`.

- **Style:** an original aviation operations look. It doesn't copy any airline's brand.
- **Colours:** dark navy panels with cockpit-style status colours: cyan for information, green for normal or approved, amber for caution, and red for warning.
- **Fonts:** Barlow for text and B612, Airbus's open font, for flight data. Both load from Google Fonts.
- **Status:** colour is never the only signal; text labels always go with it.
