# Falcon Cargo Air: Re-offer Rules (fictional)

Simplified, fictional rules for a prototype. Cite them by section, for example "Reoffer 1.5". The app checks these rules in plain code; a person approves every re-offer.

## 1. Matching freed space to waiting requests

1.1 Room to sell = the flight's booking limit (capacity plus the allowed overbooking percentage) minus the weight and volume still booked.
1.2 A waiting request fits only if its weight and its volume both fit in the room to sell.
1.3 Pharma that needs 2-8 C (PIL) needs a temperature-controlled flight and a pharma-certified forwarder.
1.4 Lithium batteries (RLI) and other dangerous goods need a flight that accepts dangerous goods and a certified forwarder, and still pass the acceptance check at the terminal.
1.5 The flight must leave no later than the request's latest departure.
1.6 Among requests that fit, offer the highest rate per kg first. If rates are equal, the earliest request goes first.
1.7 A re-offer is a proposal until a person approves it. It is not a booking until the forwarder accepts.
1.8 A waiting request fits only if its cargo can be at the terminal by the flight's acceptance cut-off.
1.9 After the acceptance cut-off, freed space can be shown but no longer re-offered.
